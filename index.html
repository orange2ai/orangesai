关于

你好，我是橘子

我本名冯雷，网上大部分时候叫橘子，也有人按我的英文名 Orange 找我。以前在 MiniMax 工作，现在是自己创业，做 AI 产品。

现在的重心是 ColaOS。它不像一个对话框，更像一个住在你电脑里、记得你是谁、能替你在各种应用之间动手的东西。在此之前我们做了 ListenHub，把文字变成音频；还有 Labnana，一个 AI 图像生成工具。

产品之外我写文章，也做播客。我写《互联网已死，Agent永生》，也写过《离开 Claude，发现外面根本没下雨》。现在和杨攀、歸藏、向阳乔木一起做 AI 视频播客《Next Token · 词元之外》，每周一场开放圆桌。我自己还做一档一对一的思想实验对谈，叫「橘座」。

我每天六点多起床，习惯是先把想法变成能跑的东西，再去想它值不值得。

在做

产品

  • ColaOSAgent OS

    世界上第一个有灵魂的操作系统。它记得你、有自己的觉知和牵挂，可以在你的电脑里跨应用替你办事。我们现在把全部精力放在这里。

  • ListenHubAudio · Video

    把任何东西变成声音的地方。一段文字、一个链接、一份文件，进去，出来的是播客、配音、图片和视频。

  • LabnanaImage

    AI 图像生成工作台，把 Nano Banana、GPT-Image-2、Seedream 这些模型放在一起用。

  • Next Token / 词元之外Podcast

    AI 视频播客，四位主理人的开放圆桌。我负责的其中一档是我一个人的对谈实验，叫「橘座」。

Creative Archive

顺手做的小东西

  • Clean X UpChrome

    一个把 X 上那些让人分心的东西拆掉的浏览器扩展：未读角标、新帖提示、右侧栏、标签页数字。

  • Coucou BikeiOS

    骑车的时候有一只鸟在你耳机里报数：速度、距离、心率，说给你听。开源的 iPhone 应用。

  • Claude Code NowmacOS

    最快打开 Claude Code 的方式。点一下 Dock，或者从任意文件夹直接启动。

  • Pelican on a BicycleGame

    一只鹈鹕骑自行车的可玩 canvas 小游戏。

  • Disk RaccoonmacOS

    macOS 缓存清理 agent，先把缓存画成地图，再决定吃什么。第一次实战一晚清出 135GB。

  • Flash TranslatemacOS

    极简的菜单栏划词翻译：选中就翻译。
